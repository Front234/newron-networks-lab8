## Лабораторная работа "Обработка временных рядов с помощью нейронных сетей"

## Структура репозитория

-`lab8Lite.ipynb` – ноутбук для задания Lite: создание и визуализация работы полносвязного классификатора жанров музыки 

-`lab8Pro.ipynb` – ноутбук для задания Pro: разработать сверточный классификатор музыкальных жанров на базе Conv1D, представив аудиофайлы как последовательности признаков фиксированной длины, полученных скользящим окном, и добиться точности классификации не ниже 60% на тестовых данных.

-`lab8Ultra_Pro.ipynb` – ноутбук для задания Ultra Pro: разработать классификатор эмоций по аудио на датасете TESS с точностью не менее 98% на тестовой выборке, затем проверить обученную модель на выбранных файлах датасета SAVEE и сделать выводы о качестве распознавания.

-`lab8Pytorch.ipynb` – ноутбук для задания Lite: создание и визуализация работы полносвязного классификатора жанров музыки 

## Требования

Для запуска ноутбуков рекомендуется использовать **Google Colab**. Все необходимые библиотеки предустановлены в Colab.
